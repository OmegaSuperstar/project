# League of Legends Champions Library

A web app built with React that displays a searchable and filterable library of League of Legends champions. Browse through all available champions, view detailed stats, abilities, and more!

## 🚀 Features

- 🧠 Full list of champions fetched dynamically from Riot's Data Dragon API
- 🔍 Real-time search by champion name
- 🛡️ Filter by champion roles (e.g., Assassin, Mage, Tank, etc.)
- 📊 View detailed info: stats, abilities, lore, and splash art
- ⚡ Responsive and lightweight UI built with React

## 🛠️ Tech Stack

- React
- Axios (for API requests)
- CSS Modules / Styled Components (depending on your implementation)
- Riot Games Data Dragon API
